# Project Overview - Project คืออะไร

- Online Coffee Shop Mobile Application

# Objective - วัตถุประสงค์

- Sell coffee and related products online
- Allow customers to brows and products
- Allow admins to manage products, orders, and customers
- Support pickup and delivery options
- Support various payment methods
- Track order status
- Send notifications to customers about their order status
- Support Cross-platform
- Easy to use and user-friendly interface
- Secure login and registration
- Responsive design for all devices
- Fast loading time
- Easy to navigate
- Easy to find products
- Easy to checkout
- Easy to track orders
- Easy to contact customer support

# Business Rules - มีกฏกติกาอะไรบ้าง

- Must be over 18 to order
- Must login to order
- Must logout to close session
- Must provide valid payment information
- Product quantity must be greather than 0
- Order total is calculated from product price and quantity
- Payment must be made before order is processed
- Order must be confirmed before order is processed
- Order must be cancelled before order is processed
- Order must be refunded before order is processed
- Order status must follow the defined order workflow

# Constraints - ข้อจำกัด

- Mobile Application
- Cross-platform
- Must use a relational database
- Must support Customer and Adimn role
- Must support real-time updates
- Must support push notifications
- Must support location-based services
- Must support payment gateway integration
- Must support social login
- Must support face id and touch id
